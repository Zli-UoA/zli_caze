# Caze (beta)

A real-time room app (React Router + Vite+ + TanStack DB + Cloudflare Workers) that lets you join a room by ID and post comments. A separate `/room/:roomId/view` page renders them as scrolling danmaku on canvas.

## Getting Started

> Package manager: pnpm (via `packageManager`). Do not use npm. Node version is pinned via `.node-version` (Vite+ 1.4 / Vitest 5 requires `^22.18.0 || ^24.11.0 || >=26.0.0`).

Install dependencies:

```bash
pnpm install
```

### Development

Start the development server with HMR:

```bash
pnpm run dev
```

Your application will be available at `http://localhost:5173`.

## Checks

```bash
pnpm run typecheck   # cf-typegen + react-router typegen + tsc -b
vp check              # Oxfmt + Oxlint (type-aware)
vp test               # Vitest (node environment, src/**/*.test.{ts,tsx})
vp build              # production build
```

## Preview / Deploy

```bash
pnpm run preview     # build && vp preview
pnpm run deploy      # build && wrangler deploy
```

## Notes

- `@tanstack/db` and `@tanstack/react-db` must be upgraded together (exact pins: `0.4.1` / `0.1.23`).
- `worker-configuration.d.ts` is generated by `pnpm run cf-typegen` (`wrangler types`).
